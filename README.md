# Hariharan Mudaliar – Resume & Cover Letter

This repository contains the LaTeX source files for the resume and cover letters of Hariharan Mudaliar.

## Files

- **polished.tex**: The main resume file, featuring education, technical skills, experience, projects, patents, publications, certifications, awards, and extracurricular activities.
- **cover_letter_arise.tex**: A motivational, experience-driven cover letter tailored for an application to Arise App, highlighting AI, mobile, and user-focused achievements.

## How to Use

1. **Compile with LaTeX**
   - Use any LaTeX editor (such as Overleaf, TeXShop, or VS Code with LaTeX Workshop) to compile the `.tex` files into PDF format.
   - Example command:
     ```
     pdflatex polished.tex
     pdflatex cover_letter_arise.tex
     ```

2. **Customization**
   - Edit the `.tex` files to update your information, add new experiences, or tailor the cover letter for other applications.
